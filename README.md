Thunder Executor is a Windows application for loading Lua scripts, organizing execution tasks, and accessing a built-in Roblox script hub from one focused workspace. Its small desktop UI is built around batch execution, debugging support, and a queue that remains available between sessions.

The v3.4 release is intended for users seeking a Roblox script injector-style utility with update support and a substantial script collection. ### What is Thunder Executor focused on?
The project combines a compact desktop interface with a large script hub, sequential batch execution, and debugging tools in a single package.

### Could script executor use put my Roblox account at risk?
The account and usage risks associated with script executors vary according to the scripts used and how the software is operated. Check Roblox's terms and assess your own environment before using the application.

### Where are scripts and queue entries kept?
Queue data is stored locally through SQLite. This allows script entries and execution history to remain on the device for later use.
